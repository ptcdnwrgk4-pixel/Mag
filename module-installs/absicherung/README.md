# Modul: Absicherung

Richtet die Basis-Sicherung für dein CEO-GPT ein.

**Was du bekommst:**
- Git-Versionskontrolle (lokal)
- Remote-Backup auf GitHub oder GitLab (privat)
- `.gitignore` die deine API-Keys schützt

**Wie du es einrichtest:**
In Claude Code: `/install module-installs/absicherung`

**Was du brauchst:**
- Einen kostenlosen Account auf GitHub (github.com) oder GitLab (gitlab.com)
- Ca. 10 Minuten

**Voraussetzungen:**
- Git muss installiert sein (`git --version` im Terminal prüfen)
- Falls nicht: https://git-scm.com/downloads
